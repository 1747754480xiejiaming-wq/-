# 茶序原型验收记录

日期：2026-09-11。环境：本机 Chromium 内嵌浏览器、React + TypeScript + Vite。本表记录实际浏览器操作结果，不表示后端或生产系统验收完成。

| 检查项 | 实际结果 |
|---|---|
| 首页与 SKU 检索 | `LJ-050` 返回 2026/2025 两个已发布批次，草稿未公开 |
| 首页滚动信息架构 | 首页、茶史四章、茶叶品类、参考资料与联系我们组成七幕固定顺序；茶史每个小板块均为独立滚动场景 |
| 桌面 Sticky 滚动 | 1440×900 下舞台保持 `position: sticky`；滚动停止后自动吸附到最近一幕，PageDown 连续停驻于 `0/812/1624/2436/3248/4060/4872`；页面无横向溢出 |
| 场景重影 | 七幕使用单幕互斥显示；桌面逐幕检查时每个停驻位置只有一个场景为可见状态，首页文字、茶史文字和插画不再叠加 |
| 首页滚动提示间距 | 桌面端竖排 `SCROLL TO EXPLORE` 向左移入页面留白区，与“循着时间认识茶”等操作链接分离；默认桌面和 1440×900 视口均未裁切 |
| 首页锚点导航 | `?section=history` 定位第一章；`categories` 与 `references-contact` 分别定位第六、七幕；茶史四幕均高亮“茶的历史” |
| 移动端滚动 | 390×844 下七幕回到真实 DOM 文档流，使用 `scroll-snap-type: y proximity`，隐藏桌面进度轨；首页、茶史、品类和联系深链接均准确停驻且无横向溢出 |
| 空结果恢复 | 无匹配时显示空态；清除筛选恢复 3 条公开记录 |
| 茶品详情 | SKU、批次、内容版本和专属/通用方案区分明确 |
| 资料来源弹窗 | 显示演示来源与使用范围，Escape 可关闭；移动端可读 |
| 过期货源 | 2025 批次提示暂无有效报价，隐藏参考价与库存信息 |
| 有效货源 | 2026 批次显示示例参考价、有效期、规格和样品入口 |
| 样品入口 | 自动选中样品申请；不产生订单 |
| 冲泡过程 | 四步可逐步推进；计时由 00:30 递减至 00:09，暂停后可重置；完成并反馈后可进入货源 |
| 咨询校验 | 空提交显示需求、联系方式、同意项错误；填示例后仍要求主动同意 |
| 咨询回执 | 提交后展示编号、批次和 `d***@example.com`；同一条记录进入后台 |
| 线索跟进 | 新增记录可更新为已联系；保存后列表状态更新 |
| 问答状态 | 已验证有依据回答、资料不足、健康边界、离线降级 |
| 问茶自动带入冲泡 | “西湖龙井怎么泡”自动选择 `2026-SPR-A` 并填入 3g/85°C/150ml/30秒；祁门问题填入 5g/90°C/150ml/20秒；非泡法问题会收起上一份冲泡方案 |
| 旧冲泡链接兼容 | `#/brew/longjing-2026` 进入合并后的问茶页并直接展开龙井四步冲泡方案 |
| 草稿隔离 | 修改说明并提交审核后，前台仍显示原 v2.0 和原说明 |
| 审核与发布 | 审核页仅提供“通过并自动发布”和“退回修改”；通过逻辑在同一状态迁移中更新公开版本 |
| 商品上下架与删除 | 数据运营和项目管理员在已发布商品上看到“下架”，在已下架商品上只看到“重新上架”；重新上架无需复审，来源撤回时同步恢复演示来源并立即返回用户端；数据运营仅能删除草稿，管理员可删除商品 |
| 来源撤回 | 确认撤回后列表为 0 条并显示资料不可用；问答显示无法确认 |
| 导入样例 | 错误样例定位到第 3 行 name/sku/category；正确样例可导入草稿，未自动公开 |
| 四套职能平台 | 四种身份分别显示数据运营、客户审核、线索跟进、项目管理的导航、概览和待办；越权路由显示职能边界空态 |
| 操作日志 | 显示咨询、草稿、审核、发布、下线、跟进、导入及来源撤回等操作 |
| 数据重置 | 恢复初始茶品、来源和两条线索；测试业务数据已清理 |
| 响应式 | 1440 桌面、768 后台平板、390 首页/详情、375 咨询/冲泡/问答/后台无整页横向溢出；宽表格在容器内滚动 |
| 移动导航 | 底部导航与后台折叠菜单可切换页面；移动来源弹窗正常 |

本轮新增复核：内容与导入合并页面、审核待办和商品操作均通过浏览器 DOM 检查；数据运营与项目管理员均显示下架入口；上架/下架按状态互斥。已在隔离浏览器来源状态中验证“来源撤回→重新上架→来源恢复→用户端重新显示”，内容 revision 不变且未进入待审核状态。正式演示数据未被测试流程覆盖。

截图：`01`–`10` 为桌面流程，`11`–`16` 为移动页面，`17` 为后台平板。截图中部分测试数据和提示属于当时状态；当前演示数据已重置。

未作为通过项：真实网络重试与服务端幂等、并发写冲突、真实文件上传端到端、XLSX、账号登录、后端权限验证、真实大模型与 RAG、全量历史版本、跨浏览器兼容性和屏幕阅读器专项。CSV 的本轮浏览器验收使用内置样例；上传选择器和下载文件内容未单独自动验证。没有宣称这些能力已经联调完成。

最终构建：`npm run build` 通过（TypeScript 检查与 Vite 生产构建）。本轮在 1440×900 桌面视口使用 PageDown 逐幕检查七个吸附位置、单幕可见状态、导航分组、Sticky 状态与横向溢出；在 390×844 移动视口检查七幕真实文档流、原生邻近吸附、历史深链接和进度轨隐藏。既有 `#/catalog`、`#/qa`、`#/admin` 回归结果继续有效。
