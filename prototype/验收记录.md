# 茶序原型验收记录

日期：2026-09-10。环境：本机 Chromium 内嵌浏览器、React + TypeScript + Vite。本表记录实际浏览器操作结果，不表示后端或生产系统验收完成。

| 检查项 | 实际结果 |
|---|---|
| 首页与 SKU 检索 | `LJ-050` 返回 2026/2025 两个已发布批次，草稿未公开 |
| 空结果恢复 | 无匹配时显示空态；清除筛选恢复 3 条公开记录 |
| 茶品详情 | SKU、批次、内容版本和专属/通用方案区分明确 |
| 资料来源弹窗 | 显示演示来源与使用范围，Escape 可关闭；移动端可读 |
| 过期货源 | 2025 批次提示暂无有效报价，隐藏参考价与库存信息 |
| 有效货源 | 2026 批次显示示例参考价、有效期、规格和样品入口 |
| 样品入口 | 自动选中样品申请；不产生订单 |
| 冲泡过程 | 四步可逐步推进；计时由 00:30 递减至 00:09，暂停后可重置；完成并反馈后可进入货源 |
| 咨询校验 | 空提交显示需求、联系方式、同意项错误；填示例后仍要求主动同意 |
| 咨询回执 | 提交后展示编号、批次和 `d***@example.com`；同一条记录进入后台 |
| 线索跟进 | 新增记录可更新为已联系；保存后列表状态更新 |
| 问答状态 | 已验证有依据回答、资料不足、健康边界、离线降级 |
| 草稿隔离 | 修改说明并提交审核后，前台仍显示原 v2.0 和原说明 |
| 审核与发布 | 审核页仅提供“通过并自动发布”和“退回修改”；通过逻辑在同一状态迁移中更新公开版本 |
| 商品下架与删除 | 项目管理员在商品列表直接看到下架和删除按钮；下架确认明确关闭公开详情与咨询入口；数据运营仅能删除草稿 |
| 来源撤回 | 确认撤回后列表为 0 条并显示资料不可用；问答显示无法确认 |
| 导入样例 | 错误样例定位到第 3 行 name/sku/category；正确样例可导入草稿，未自动公开 |
| 四套职能平台 | 四种身份分别显示数据运营、客户审核、线索跟进、项目管理的导航、概览和待办；越权路由显示职能边界空态 |
| 操作日志 | 显示咨询、草稿、审核、发布、下线、跟进、导入及来源撤回等操作 |
| 数据重置 | 恢复初始茶品、来源和两条线索；测试业务数据已清理 |
| 响应式 | 1440 桌面、768 后台平板、390 首页/详情、375 咨询/冲泡/问答/后台无整页横向溢出；宽表格在容器内滚动 |
| 移动导航 | 底部导航与后台折叠菜单可切换页面；移动来源弹窗正常 |

本轮新增复核：内容与导入合并页面、审核待办、管理员商品操作均通过浏览器 DOM 检查；四种身份切换后标题与侧栏同步变化；浏览器 error/warn 日志为空。下架和删除的破坏性确认按钮只检查到确认弹窗，未在本轮浏览器会话实际执行。

截图：`01`–`10` 为桌面流程，`11`–`16` 为移动页面，`17` 为后台平板。截图中部分测试数据和提示属于当时状态；当前演示数据已重置。

未作为通过项：真实网络重试与服务端幂等、并发写冲突、真实文件上传端到端、XLSX、账号登录、后端权限验证、真实大模型与 RAG、全量历史版本、跨浏览器兼容性和屏幕阅读器专项。CSV 的本轮浏览器验收使用内置样例；上传选择器和下载文件内容未单独自动验证。没有宣称这些能力已经联调完成。

最终构建：`npm run build` 通过（TypeScript 检查与 Vite 生产构建）。最终浏览器 error/warn 日志查询为空。
