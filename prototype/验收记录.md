# 茶序原型验收记录

| 首页滚动信息架构 | 首页、茶史四章、茶叶品类、参考资料与联系我们组成七幕固定顺序；茶史每个小板块均为独立滚动场景 |

| 场景重影 | 七幕使用单幕互斥显示；桌面逐幕检查时每个停驻位置只有一个场景为可见状态，首页文字、茶史文字和插画不再叠加 |

| 有效货源 | 2026 批次显示示例参考价、有效期、规格和样品入口 |

| 冲泡过程 | 四步可逐步推进；计时由 00:30 递减至 00:09，暂停后可重置；完成并反馈后可进入货源 |
