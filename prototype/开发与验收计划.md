# 茶序前端原型实施计划

目标：落实已获用户确认的茶序视觉与 MVP 页面范围，交付可点击、可输入、可验证业务状态的 React 原型。前后端接口契约作为业务依据；所有数据为明确标识的演示数据，不调用真实模型、不发送咨询、不模拟真实授权。

用户已批准米白、深茶绿、朱砂点缀及用户端/后台/移动端范围，授权常规设计阶段检查自行完成。

Figma 文件 cRMwXR1psHjb4MgkhD5WC2 已建基础变量和组件。Figma 保持主设计画布；只有在操作明确触发付费限制或额度耗尽时，才将受阻部分转到 Penpot。Penpot 产物需沿用同一套设计令牌并回填关联记录，待 Figma 可用时再同步回主画布。当前 Starter 工具额度已耗尽，因此完整页面可先由 Penpot 承接；本地可操作原型继续作为交互验收基准，不将局部组件声称为完整 Figma 原型。

1. 建立共享设计变量、类型、示例数据和状态存储；产物 src/model.ts、src/styles.css。
2. 建立界面组件和用户端；产物 src/ui.tsx、src/PublicPages.tsx；覆盖检索、详情、冲泡、问答、货源与同意提交。
3. 建立后台与状态闭环；产物 src/AdminPages.tsx；草稿、审核、发布、撤回影响公开列表；咨询进入演示线索列表。
4. 建立路由、通知、弹窗与移动端导航；产物 src/main.tsx；浏览器回退有效，键盘操作与表单错误可见。
5. 执行构建和浏览器人工式联调；先核对真实界面，再按观测控件操作；检查 1440、768、390、375 宽度，浏览器无横向溢出。
6. 保存截图和具体通过/未实现项；产物 output/playwright 和 prototype/验收记录.md。

必须验证：茶类/批次区分；空结果；无有效来源；过期货源隐藏价格；泡茶计时和完成；咨询主动同意与重复提交；后台不同角色权限；审核与发布分开；撤回公开内容；导入错误；问答无来源/健康边界/离线；移动端导航与弹窗。

Skill 分工：brainstorming 为已批准设计；writing-plans 组织交付步骤；figma-use/figma-generate-library 为主画布和初始设计系统；figma-generate-design 用于规划页面复用；Penpot AI Kit 仅在 Figma 付费限制发生时承接受阻画布；playwright 为浏览器检查。当前 Figma 到代码不是已有完整设计的像素还原，不声称经过 get_design_context 的 1:1 设计实现。
