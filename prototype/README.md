# 茶序 · 茶文化智能体交互原型

按已确认的「米白、深茶绿、朱砂」方案制作。用户端与管理后台共用同一份本机演示状态，支持桌面、平板和移动端。

## 打开与启动

- 用户端：http://127.0.0.1:4173/
- 后台：http://127.0.0.1:4173/#/admin
- 入口源码：`src/main.tsx`

在本目录运行：

```powershell
npm ci
npm run dev
```

已安装依赖时只需 `npm run dev`。当前会话已启动服务；若地址无法打开，重新运行即可。构建检查使用 `npm run build`；构建结果位于 `dist`，需通过 HTTP 服务打开，不能直接双击 HTML。此地址仅供本机访问。

## 版本快照

每次代码或设计画布改动完成并验证后，都要创建独立 Git 提交并推送到项目 GitHub 仓库。画布改动还需在项目根目录 `design-snapshots/` 保存 Figma/Penpot 链接、节点、版本说明和截图或导出物。完整规则见项目根目录 `AGENTS.md`，快照索引见 `VERSION_SNAPSHOTS.md`。

## 建议体验顺序

1. 首页搜索 `LJ-050`，对比龙井两个批次；进入 2026 批次查看资料、功效与来源。
2. 进入分步冲泡，完成准备、投茶、注水计时、品饮；完成后查看货源。
3. 申请样品，使用「填入示例内容」，主动勾选用途同意后提交，查看脱敏回执。
4. 在后台切换「线索跟进」，查看新增需求并保存跟进状态。
5. 切换「数据运营」，编辑一款已发布茶品的资料说明，保存草稿并提交审核。
6. 切换「客户审核人」，审核通过后单独发布；公开版本在发布前保持原样。
7. 体验错误导入、内容下线、来源授权撤回；通过「重置演示数据」恢复初始示例。

## 页面与交互范围

| 范围 | 页面与主要行为 |
|---|---|
| 用户端 | 首页、检索/茶类筛选、SKU 与批次详情、功效与适饮、资料来源弹窗、有效/失效货源 |
| 冲泡 | 四步引导、专属/通用提示、参数调整、计时开始/暂停/重置、完成反馈 |
| 问答 | 示例回答与引用、无法确认、健康边界提示、离线降级 |
| 咨询 | 茶品咨询/样品申请、字段校验、主动同意、提交中状态、脱敏回执 |
| 内容运营 | 概览、内容列表、资料说明编辑、草稿/审核/发布/下线、版本对比、来源撤回 |
| 导入与线索 | CSV 上传入口及校验、预置错误/正确样例、导入草稿、线索筛选、状态跟进、脱敏导出 |
| 权限 | 四种演示角色、操作限制、权限矩阵、管理员操作记录 |

Figma 文件：[茶序 · 茶文化智能体产品原型](https://www.figma.com/design/cRMwXR1psHjb4MgkhD5WC2)。已创建 53 个变量、9 个文字样式以及 Button、Input、Badge 组件。Figma 仍是本项目的主设计画布和最终设计索引；免费额度可用时优先在 Figma 继续维护。

当 Figma 明确要求升级付费方案、调用额度耗尽或相同操作只能付费完成时，才把受阻的页面或组件转到 Penpot。迁移前记录 Figma 页/节点、版本和阻塞原因；Penpot 沿用相同令牌、组件名称、页面尺寸与交互说明，并把 Penpot 链接回填到设计清单。可再次使用 Figma 后，新增设计应同步回 Figma，避免两套画布长期分叉。详细规则见 `设计画布工作流.md`。

## 与正式前后端开发的边界

接口规范仍以项目根目录 `茶文化智能体_前后端接口契约与Skill清单.md` 为准，本轮没有修改该契约。本原型验证页面流转与业务状态，不代表已经完成真实 HTTP 接口联调。

- 数据保存在本机浏览器 localStorage；跨设备不共享。所有资料、供应主体、价格和线索均为演示。
- 问答是可控的示例状态，没有连接真实模型或检索服务；引用没有冒充真实研究资料。
- 联系方式在写入本机记录前脱敏；没有发送咨询，也没有支付或订单。
- 后台身份可切换以验证交互；正式会话、权限、审稿身份隔离、并发版本、幂等、审计持久化必须由后端实现。
- 当前编辑器可修改资料说明；完整结构化配方、资料附件、授权管理、账号创建等正式表单仍需后续开发。
- CSV 解析运行在浏览器；XLSX、服务端文件存储、正式全字段校验和导入任务接口尚未接入。
- 演示版本对比仅保留当前公开内容与工作草稿；完整历史版本查询依照正式契约实现。
- 字体可从 Google Fonts 加载；无法联网时使用本机中文字体。茶盏与茶山插画为代码内的原创 SVG。

验证详情见 `验收记录.md`，截图位于项目根目录 `output/playwright/`。
