# 茶序设计画布工作流

## 设计源优先级

1. Figma 是主设计画布、组件索引和最终交付入口。
2. React 原型是交互行为与响应式验收基准。
3. Penpot 只承接 Figma 因付费方案或工具额度而无法继续的画布工作。

## 切换到 Penpot 的条件

满足以下任一条件才切换：

- Figma 明确提示需要升级付费方案；
- Figma MCP 或账户调用额度已经耗尽；
- 当前方案不提供完成该组件、页面或原型连线所需能力。

普通报错、网络失败或操作脚本问题不直接视为付费限制，应先排查并重试。

## 切换记录

转到 Penpot 前记录：Figma 文件链接、页面与节点 ID、最后可用版本、受阻操作和阻塞提示。Penpot 页面使用 `茶序 / <端> / <页面> / Fallback` 命名，并在页面说明中写回 Figma 来源。

Penpot 必须复用以下规则：米白、深茶绿、朱砂点缀；桌面 1440、平板 768、移动 390/375；沿用 Figma 中的变量语义、组件名称、状态和中文文案；以 React 原型验证交互顺序和异常状态。

## 回同步规则

Figma 能继续编辑后，把 Penpot 中已确认的页面和组件同步回 Figma，并在设计清单中记录对应关系。同步完成前，Penpot 链接是受阻部分的临时设计源；同步完成后，Figma 恢复为唯一主设计源。禁止同时在两端独立修改同一页面。
